# Devir notu — 2 Ekim 2026

## Bu oturumda yapılanlar

- `LICENSE` AGPL-3.0'dan GPL-3.0 metnine çevrildi (FSF'nin resmi metni).
- Tauri 2 + React + TypeScript + Vite iskeleti kuruldu.
- Rust çekirdeği modüllere ayrıldı: `audio` (64-bit `Sample` türü), `analysis`, `visual_bridge`, `commands`.
- Karşılama ekranı: koyu zeminde, eski araba teybi ekranı havasında nokta matris ekran. Özgün 5x8 Türkçe
  yazı tipi (`src/lib/dotFont.ts`), kayan yazı, gösteri modu spektrumu. Ani parlama yok; "animasyonları azalt"
  tercihine uyuyor.
- Özgün program simgesi (`src-tauri/icons/icon.svg`, diğer boyutlar `npx tauri icon` ile üretildi).
- Windows NSIS kurulumu: kullanıcı başına kurulum (yönetici izni gerekmez), Türkçe arayüz, WebView2 yükleyicisi gömülü.
- CI (`.github/workflows/ci.yml`): TypeScript ve Rust testleri, lint, biçim, lisans denetimi; PR'larda Windows kurulum dosyası.
- Test sürümü (`.github/workflows/test-surumu.yml`): `main` her güncellendiğinde `test-surumu` Release'i yenileniyor.
- Lisans denetimi: `src-tauri/deny.toml` (cargo-deny) ve `scripts/check-licenses.mjs` (npm).
- Türkçe hata kaydı formu, CLAUDE.md, docs/ROADMAP.md, İngilizce README taslağı.
